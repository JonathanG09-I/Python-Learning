# Python Learning Portfolio

Colección de ejercicios introductorios desarrollados para practicar los fundamentos del lenguaje Python.

## Ejercicios

| Archivo | Descripción | Conceptos practicados |
|---|---|---|
| `01_hello_world.py` | Muestra mensajes en la consola. | `print()` |
| `02_clasificacion_edad.py` | Clasifica a una persona según la edad ingresada. | `input()`, conversión a entero, `if`, `elif`, `else` |
| `03_calificacion_estudiante.py` | Indica si una calificación alcanza el mínimo de aprobación. | `input()`, conversión a decimal, operadores de comparación, condicionales |
| `04_celsius_a_fahrenheit.py` | Convierte una temperatura de Celsius a Fahrenheit. | Variables, `input()`, conversión a decimal y operaciones aritméticas |

## Requisitos

- Python 3 instalado.
- No se necesitan librerías externas.

## Cómo ejecutar

Abre una terminal en la carpeta del proyecto y ejecuta cualquiera de los archivos, por ejemplo:

```bash
python ejercicios/01_hello_world.py
```

Puedes reemplazar `01_hello_world.py` por el nombre de cualquiera de los otros ejercicios.

## Objetivo

Practicar los conceptos básicos de Python mediante pequeños programas de entrada, procesamiento y salida de datos.

---

**Nota:** Estos ejercicios representan una etapa inicial de aprendizaje. Se conserva su lógica original como evidencia del trabajo realizado.
